# 创建 Gunicorn 服务
安装anno编辑器               sudo yum install nano -y
新建服务文件                 sudo nano /etc/systemd/system/myapp.service
写入服务文件
```
[Unit]
Description=Gunicorn Service for Flask App
After=network.target

[Service]
User=admin
WorkingDirectory=/服务器上项目目录
ExecStart=/home/admin/.local/bin/gunicorn -w 4 -b 127.0.0.1:5000 day13.app:app

Restart=always

[Install]

WantedBy=multi-user.target
```
查看                        cat /etc/systemd/system/myapp.service
启动服务                    sudo systemctl daemon-reexec
                                sudo systemctl daemon-reload
                                sudo systemctl start myapp
查看运行状态                 sudo systemctl status myapp
重新加载+启动                sudo systemctl daemon-reload
                                sudo systemctl restart myapp
停止服务                    sudo systemctl stop myapp


# 容器
构建镜像容器                  sudo docker build --no-cache -t 容器名 .    (注意: 构建时需在当前容器名目录下)
运行容器                   sudo docker run -d -p 端口:端口 容器名
查容器                   sudo docker ps     (查看运行的容器)
                                sudo docker ps -a   (查看全部容器)
看日志                   sudo docker logs 容器ID
停止容器                  sudo docker stop 容器ID
删除容器                  sudo docker rm 容器ID
    删除多个                    sudo docker 容器ID 容器ID

# 容器编排
创建docker-compose.yml  (项目根目录创建)
version: "3"

services:
  user_service:
    build: ./user_service
    container_name: user_service
    ports:
      - "5001:5001"

  auth_service:
    build: ./auth_service
    container_name: auth_service
    ports:
      - "5002:5002"
一键启动                    sudo docker compose up -d   (项目根目录)
查看运行的docker compose     sudo docker compos ps 
停止                      sudo docker compose down
重新构建镜像并启动容器编排   sudo docker compose up -d --build   (项目根目录)

进入 MySQL 容器           sudo docker exec -it mysql mysql -uroot -p  (项目根目录)
