# re.sub()
作用: 正则替换字符串
语法: re.sub(pattern, replacement, text)
示例:
```python
import re

text = "Hello, world!"

result = re.sub(r"[^\w\s]", "", text)

print(result)
```

# logging.basicConfig(...)

# return error(...) 与 raise APIException(...)
return error(...) 当前函数结束，直接返回结果，流程是“正常流程”
raise APIException(...) 中断当前函数（后面代码不执行，交给全局异常处理，流程是“异常流程”

# User.query.filter_by(name=name).first() 
表示使用 SQLAlchemy ORM 从 users 表中查询 name 等于指定值的用户，并返回第一条记录。如果不存在则返回 None。
