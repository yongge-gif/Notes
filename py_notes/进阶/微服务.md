# 字段不一致问题（接口参数问题）: UserService 中使用 username，但请求使用的是 name
结果：导致查询/登录失败
解决：统一字段名为 name

# 本地访问问题（网络监听问题）: 服务只能本地访问，外部访问不到
原因：Flask 默认只监听 127.0.0.1
解决： app.run(host="0.0.0.0")

# 端口访问问题（云服务器安全组）: 外网无法访问 5002 端口
原因：云服务器安全组未开放端口
解决：在安全组中添加入方向规则：5002 端口放行

# 数据类型跨系统问题（JWT核心问题🔥）: jwt.encode() 返回 bytes
Flask 返回 JSON 时报错： TypeError: Object of type 'bytes' is not JSON serializable
解决： if isinstance(token, bytes):
    token = token.decode("utf-8")
不同 Python / 库版本行为不同
跨环境开发必须考虑数据类型兼容

# 依赖版本冲突问题: AttributeError: module 'sqlalchemy' has no attribute '__all__'
                  ImportError: cannot import name 'url_quote' from 'werkzeug.urls'
说明: Flask-SQLAlchemy 和 SQLAlchemy 版本不兼容
      Flask 和 Werkzeug 版本不兼容
解决: 推荐稳定版本: Flask-SQLAlchemy==2.5.1 SQLAlchemy==1.4.49
                  Flask==2.2.5 Werkzeug==2.2.3

# 容器依赖中执行了全局依赖更新，构造容器生成错误依赖 
解决: 手动删减各服务依赖,只保留 Flask==2.2.5 Werkzeug==2.2.3 Flask-SQLAlchemy==2.5.1 SQLAlchemy==1.4.49 requests PyJWT
                            pymysql cryptography

# 容器测试登录失败报错: Name or service not known: user_service
原因: 两个容器不在同一个 docker 网络里
解决: 手动创建一个 docker 网络

# 容器测试数据库连接报错 Can't connect to MySQL server on '127.0.0.1'
原因: MySQL不在这个容器中
解决: 把数据库连接改成： mysql+pymysql://root:密码@服务器内网IP:3306/数据库名
MySQL 必须允许远程连接：
GRANT ALL PRIVILEGES ON *.* TO 'root'@'%' IDENTIFIED BY '密码';
FLUSH PRIVILEGES;

# 什么是“数据卷（volume）”
本质 ：👉 把容器的数据映射到宿主机

# 容器编排启动端口冲突问题: 3306: bind: address already in use
原因: 宿主机的 3306 端口已经被之前的MYSQL容器占用
解决: 改 docker-compose.yml 中 mysql端口ports:
      由 - "3306:3306" 改为 - "3307:3306"         意思： 宿主机：3307 容器内部：3306（不变）

# MySQL 8 + Python 驱动问题: 'cryptography' package is required for sha256_password or caching_sha2_password
原因: MySQL 8 加密方式 → Python 需要 cryptography 支持
解决:安装依赖 在各服务需求中手动添加cryptography  各服务更新需求 pip3 freeze > requirements.txt
